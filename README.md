# ✦ Звездна карта — лична астрология на български

Прогресивно уеб приложение (PWA) за лична **натална карта** на български език.
Работи директно в браузъра, може да се добави на началния екран на iPhone/Android
и работи и **офлайн**. Без build процес — чист HTML/CSS/JavaScript, готово за GitHub Pages.

## Какво прави

1. **Рождени данни** — дата, точен час и място (падащо меню с големите български
   градове с готови координати + опция за ръчно въвеждане на ширина/дължина).
   Часовата зона на България (EET/EEST) се определя автоматично според датата.
2. **Точна натална карта** — самостоятелен астрономически двигател изчислява позициите
   на Слънцето, Луната и планетите (приближени кеплерови елементи на JPL + алгоритми на
   Meeus), Асцендент, Среден небосвод (MC), домове по системата **Placidus** и аспектите.
3. **Визуализация** — зодиакалното колело с планети, домове и аспекти (SVG), а до него —
   подробни описания на достъпен български език, без жаргон.
4. **Локално съхранение** — рождените данни се пазят в браузъра (`localStorage`),
   за да не се въвеждат повторно.
5. **Екран „Днес“** — всеки ден кратко рефлексивно послание, съобразено с картата ви.

## Стартиране локално

Понеже има service worker, отворете през локален сървър (а не `file://`):

```bash
python3 -m http.server 8000
# след това отворете http://localhost:8000
```

## Публикуване на GitHub Pages

1. Отидете в **Settings → Pages** на хранилището.
2. За **Source** изберете клона на проекта и папка `/ (root)`.
3. След няколко минути приложението е достъпно на
   `https://<потребител>.github.io/astro/`.

Всички пътища са относителни, така че работи коректно и под подпапка (`/astro/`).

## Икони

Иконите се генерират без външни зависимости:

```bash
python3 tools/generate_icons.py
```

## Структура

```
index.html              приложна обвивка
manifest.webmanifest    PWA манифест
sw.js                   service worker (офлайн)
css/styles.css          тъмен космически дизайн
js/astro.js             астрономически/астрологичен двигател
js/cities.js            български градове с координати
js/timezone.js          часова зона EET/EEST
js/interpretations.js   описания на български
js/daily.js             посланието „Днес“
js/app.js               интерфейс и визуализация на колелото
icons/                  иконите на приложението
```

## Бележка за точността

Позициите са с точност до няколко дъгови минути (повече от достатъчно за правилно
поставяне по знаци и домове) за периода ~1900–2050. Това е помощно и образователно
приложение, а не професионален ефемериден софтуер.
